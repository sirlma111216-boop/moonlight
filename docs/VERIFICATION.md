# 검증 결과와 확인하지 못한 항목

구분 기준: **완료**(실제 동작 확인) / **시연 자료로 검증**(실제 외부 자료 없이 앱 계산·로컬 자료로 확인) / **교사 키·자료 필요**(외부 설정·자료가 있어야 최종 확인 가능) / **미완료**.

실제 API 키 없이 검증한 항목과 실제 응답으로 검증한 항목을 분리했다. 이번 세션에서는 **공공데이터포털 서비스키가 없어 기관 API 를 실제 응답으로 검증하지 못했다.**
