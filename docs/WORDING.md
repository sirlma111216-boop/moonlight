# 학생 화면 쉬운 말 원칙

대상은 초등학교를 막 졸업한 중학교 1학년이다. 학생이 선생님의 설명 없이 화면만 읽어도 알 수 있어야 한다.

## 1. 용어 처리

| 갈래 | 방법 | 해당 말 |
|---|---|---|
| 교과서 용어 | 현상을 쉬운 말로 먼저 보여 준 뒤 이름을 붙인다. 밑줄을 누르면 뜻풀이를 한 번 더 볼 수 있다 | 위상, 삭, 초승달, 상현달, 보름달, 하현달, 그믐달, 월령, 공전, 일식, 월식 |
| 쉬운 말로 바꿈 | 아래 표 | 광원, 원반, 시점, 관측선, 정렬, 배치, 천체, 월출·월몰, 일몰, 본그림자·반그림자, 궤도면, 교선 |
| 학생 화면에서 뺌 | 교사 화면이나 문서로 옮김 | 판정, 허용 범위, 결측, 축척, 근사 모형, 기관 예측 자료, 앱 계산, 학습 모형, 라이브러리 이름, 각도 표기(°), km 값 |

| 예전 말 | 지금 말 |
|---|---|
| 광원 | 태양, 또는 태양 역할을 하는 전등 |
| 원반의 밝은 비율 50% | 반쪽이 보여요 (밝기를 말로: 거의 안 보여요 / 눈썹처럼 가늘게 / 반보다 조금 작게 / 반쪽 / 반보다 크게 / 거의 다 / 동그랗게 다) |
| 270° 위치, 궤도 각도 | 7번 자리 (달이 도는 길 위 1~8번 자리, 1번 = 태양 쪽) |

| 기관 예측 자료 / 앱 계산 / 학습 모형 | 천문연구원 자료 / 컴퓨터 계산 / 모형 |
| 월령 근사 모형 | 월령으로 그려 본 달 모양 |

## 2. 문장

- 한 문장에는 새 개념 하나만 넣는다.
- 숫자·퍼센트·각도 대신 모양과 자리 번호로 말한다.
- 피드백은 맞고 틀림보다 ‘다음에 해 볼 것’을 알려 준다. 해 보라고 한 조작이 오히려 반대 증거를 만들지 않는지 확인한다.
- 개발·교사용 정보(판정 기준, 계산 방식, 축척 수치)는 학생 화면에 쓰지 않는다.

## 3. 3D 모형

- 한 장면에는 조작 하나, 개념 하나만 둔다.
- 02 장면 1(전등)은 보는 자리를 위로 고정하고 학생은 전등만 옮긴다. 보는 자리에 따라 달라 보이는 것은 02 장면 2에서 ‘나’와 함께 따로 다룬다.
- 보는 자리를 마우스로 마음대로 돌리는 기능은 자유 실험에만 둔다. 수업 장면은 ‘비스듬히 / 바로 위에서 / 옆에서’ 단추만 쓰고, 지금 어디서 보는지 화면에 적는다.
- 태양·지구·달·나(또는 보는 곳)·자리 번호에 이름표를 붙인다.
