# 관측 자료 파일 자리

이 폴더에 **출처·촬영 정보가 확인된 실제 관측 사진**을 넣고 `shared/mediaManifest.ts` 의 `src` 를 채운다.

| 하위 폴더 | 들어갈 파일 | 사용 단계 |
|---|---|---|
| `observations/` | `moon-observation-1.jpg` … (날짜가 서로 다른 위상 사진, 최소 3장·권장 4~8장) | 01 · 03 · 07 |
| `eclipses/` | `eclipse-observation-solar.jpg`, `eclipse-observation-lunar.jpg` | 09 · 10 |

규칙

- 파일명에 학생·촬영자 이름을 넣지 않는다.
- 생성 이미지·시뮬레이션 렌더는 이 폴더의 ‘실사진’으로 등록하지 않는다. NASA SVS 렌더는 `kind: 'simulation'` 으로만 등록한다.
- 각 파일의 촬영자/기관, 촬영 일시·시간대(모르면 ‘미상’), 지역, 처리 내용, 이용 조건, 저작자 표시, 대체 텍스트를 매니페스트에 적는다.
- 웹용으로 2000px 이하, 500KB 이하로 줄여 넣는 것을 권장한다(학교망).

교사 콘솔의 ‘관측 자료’ 탭에서도 같은 항목으로 등록할 수 있다(그 경우 파일은 여기 두고 경로 `/media/observations/파일명` 을 적는다).
